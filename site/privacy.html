Privacy notice for the Kitlane public demo

Applies to the demonstration installation at kit.kitlane.dev. Last updated: 2026-10-08.

What the demo is

The public demo is a sample installation of Kitlane, an open-source project, provided so people can see how it works. It contains synthetic sample tools and data. It is not a service for real work. Do not enter real, personal, or confidential information.

Signing in with Google

The demo uses Google sign-in so that each visitor has a stable identity. When you sign in, Google shares your account's unique identifier, email address, and display name with the demo. The demo requests no other Google data and cannot read your Gmail, Drive, Calendar, or anything else. If your account belongs to a Google Workspace organization, the organization's domain is recorded as your "team" so the demo can show how cross-team discovery is measured.

What the demo stores

  • Your Google identifier, email address, display name, and Workspace domain, if any.
  • Anything you type into a sample tool that saves data, such as notes or preferences. Personal data is isolated to you and to the tool you typed it into. Shared collections are readable by everyone signed in to the demo.
  • Usage events for discovery measurement: which sample tool was open, whether the Explore tools drawer was opened, which recommendation was launched, and when. These use a pseudonymous session key. No text you type and no search terms are recorded in these events.
  • Standard web server logs with IP addresses and request paths, kept briefly for security and troubleshooting.

How long it is kept

The demo is reset on a schedule, which deletes all stored data including accounts, saved notes, and usage events. Usage events older than ninety days are deleted automatically even between resets. Server logs are rotated within a few weeks.

Who can see what

Other signed-in visitors can see your display name on anything you publish or edit in shared collections, and the sample tools show each tool's creator. Nobody else can see your personal notes. The person operating the demo can access the database for maintenance. Data is not sold and not shared with third parties beyond the hosting provider and Google sign-in.

Publishing

Publishing tools on the demo is limited to invited accounts. Everyone else can browse, launch, and use the sample tools. If you see something on the demo that should not be there, use the contact below and it will be frozen or removed.

Your choices

You can stop using the demo at any time. To have your data removed before the next scheduled reset, or to ask any question about this notice, contact REPLACE-ME@example.com. You can also revoke the demo's access to your Google account at myaccount.google.com/permissions.

Running your own

Kitlane is designed to be self-hosted by one organization at a time. An installation you run yourself stores its data with you and uses your own sign-in provider; this notice does not apply to it.
