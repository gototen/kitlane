Kitlane

An internal front door for the software people make. Give an employee-made tool a memorable address like kit/prep, show an Explore tools rail beside it so colleagues find what else exists while they work, and let anyone make a copy and adapt it with whatever builder they prefer.

Try the public demo   Source on GitHub

About the demo. Sign in with any Google account to browse, launch, and use the sample tools. Publishing is limited to invited accounts, the sample data is synthetic, and the demo is reset on a schedule. Do not enter real or confidential information. See the privacy notice.

What it does

  • Publish a static tool from the command line, or register an existing URL, under a short name.
  • Every hosted tool runs on its own origin inside a shell with a persistent discovery rail.
  • Tools get identity, durable personal storage, and company-readable shared collections through a small browser SDK.
  • Make a copy of any published tool, download its files, adapt them with any agent or builder, and republish with attribution.
  • Self-host for one organization with Docker Compose, your own identity provider, and your own data.

Run it yourself

Each installation serves one organization or trusted team and controls its own membership and data. The repository includes a local demonstration and a documented team deployment.
